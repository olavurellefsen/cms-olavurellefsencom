# Ólavur Ellefsen site design system

This system captures the existing public-site and Usable CMS language so future design work stays consistent with the shipped product.

## Sources consulted

- `src/app/globals.css` for color, typography, spacing, borders, controls, responsive behavior, and CMS overlays.
- `src/app/layout.tsx` for the shipped Manrope and Newsreader variable fonts.
- `src/app/page.tsx` for the Current work information hierarchy and list structure.
- `src/components/cms-editor.tsx` for top-bar, inline-edit, inspector, draft, and publish interactions.
- The user-provided CMS screenshot dated 2026-08-03 for real editing context.

## Contents

- `tokens/colors_and_type.css`: canonical raw and semantic tokens.
- `brand/voice-and-tone.md`: interface language rules.
- `brand/style-notes.md`: visual and interaction rules.

The codebase remains the source of truth; this folder is a reusable summary for design work.
