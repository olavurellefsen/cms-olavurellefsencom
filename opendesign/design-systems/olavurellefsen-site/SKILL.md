# Ólavur Ellefsen site system

Use the public page as the primary canvas. Pair Newsreader for editorial display text with Manrope for interface and body copy. Keep surfaces warm and pale, text deep green, borders quiet, and CMS actions compact and explicit. Coral is reserved for editing focus and primary actions.

For CMS interactions, prefer direct manipulation: inline text editing, contextual row controls, and a compact right-side inspector for secondary attributes. Structural controls must never appear on the public page.
